# Yusuf A. | Full-Stack Web Developer

A responsive, single-page freelance portfolio for Yusuf A.

## Preview

The source is built with Pug, Bootstrap 5.2, SCSS, and vanilla JavaScript.

```bash
npm ci
npm start
```

`npm start` builds the project, starts the local preview, and watches for source changes.

## Build

```bash
npm run build
```

The generated site is written to `dist/`.
